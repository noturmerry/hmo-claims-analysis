# Data

This project uses a **simulated HMO claims dataset** created for portfolio and analytical demonstration purposes.

The dataset contains:

- 50,000 healthcare claim records
- 20,000 member records

## Dataset Components

### Claims Data

The claims dataset contains information such as:

- Claim ID
- Member ID
- Claim date
- Service type
- Provider
- Claim amount
- Claim status
- Processing days

### Member Data

The member dataset contains information such as:

- Member ID
- Gender
- Age group
- Region
- Membership type

## Data Availability

The raw CSV datasets are **not included in this repository**.

The project uses simulated healthcare data, and the raw files are excluded from the repository to keep the portfolio focused on the analytical workflow and to avoid unnecessary exposure of individual-level records.

The analysis can be reproduced using the methodology, Python notebook, SQL queries, and Power BI dashboard included in this repository.

> **Note:** The dataset is simulated and does not contain real patient or member information.
